# Snow Keyboard

Кастомная клавиатура для Android с автокоррекцией орфографии,
авто-расстановкой точки/заглавных букв, анимированным снегом на фоне
и подсветкой нажатых клавиш.

## Что внутри

- `SnowInputMethodService.kt` — сам сервис клавиатуры (IME): обработка
  нажатий, автокоррекция, капитализация предложений, двойной пробел → точка.
- `SnowKeyboardView.kt` — кастомная отрисовка: фон-градиент, падающий снег,
  подсветка нажатой клавиши при тапе.
- `KeyboardModel.kt` — раскладка ЙЦУКЕН + цифровой/символьный слой.
- `TextCorrector.kt` — лёгкая автокоррекция (встроенный словарь +
  расстояние Левенштейна) и правила пунктуации.
- `SettingsActivity.kt` — экран, который открывает системные настройки
  клавиатур и показывает выбор клавиатуры по умолчанию.

## Как собрать и установить

1. Откройте папку `SnowKeyboard` в Android Studio (File → Open).
   При первом открытии Android Studio сама предложит докачать Gradle —
   согласитесь (нужен интернет один раз).
2. Дождитесь Gradle Sync.
3. Подключите телефон по USB (включите "Отладку по USB" в настройках
   разработчика) или запустите эмулятор.
4. Нажмите Run ▶ — приложение установится на телефон.
5. Откройте установленное приложение "Snow Keyboard" → кнопка
   "Включить клавиатуру в настройках" → включите переключатель.
6. В любом текстовом поле зажмите иконку смены клавиатуры (или нажмите
   "Выбрать клавиатуру" в приложении) и выберите Snow Keyboard.

## Что можно докрутить дальше

- Расширить словарь в `TextCorrector.kt` (сейчас ~50 частотных слов —
  этого достаточно для демонстрации, но не для полноценной орфографии).
  Для серьёзной проверки орфографии стоит подключить словарь Hunspell
  или офлайн-модель.
- Добавить свои цвета/картинку вместо снега в `SnowKeyboardView.onDraw`.
- Добавить английскую раскладку и переключение по кнопке "RU/EN"
  (сейчас кнопка LANG — заглушка).
- Добавить звук нажатия клавиш.
